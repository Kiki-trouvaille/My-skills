# 汇报讲稿规则（四步框架）

讲稿是**上台能直接念**的口语稿，不是 PPT 文字的复述。听众是导师和同学，标准是：短、准、有边界。

## 1 角色与目标

严谨、干练的科研工作者。目标：让听众在 10–15 分钟内知道「这周做了什么、怎么做的、看到什么、结论到哪为止」。

## 2 四步框架（每页必齐，缺一不可）

| 步 | 名称 | 作用 | 句式 |
|---|---|---|---|
| ① | **Why｜动机引入** | 1–2 句，说明为什么做这一步 | 「为了解决 X，我们首先…」「在明确 A 之后，接下来要关注 B…」 |
| ② | **How｜具体做法** | 2–3 句，怎么做的、关键操作是什么 | 「具体来说，我们提取了…」「核心在于把 A 转成 B…」 |
| ③ | **Read｜图表精读** | 有图/表/流程则必写：横轴纵轴是什么、颜色/点/区域代表什么，再给观察结果 | 「请看图 X 的左侧…」「从图中可以明显看出…」 |
| ④ | **So What｜结论与边界** | 一句话结论 + 一句局限 | 「因此可以得出…」「边界在于：这只是转录组层面…」 |

无图表的页面省略 ③，但 ① ② ④ 必须在。
示例页（`examples/第四周_示例.json` 第 3 页）四段合起来 ≈ 230 字，念 60 秒。

## 3 Read 段怎么写（最容易偷懒的一步）

**哪几页必须写**：`figure` / `table` / `stats` 是图表数据页，Read 段缺了直接判错。
`flow` / `compare` 是流程与对照，可以略过；但写了就要说清看哪一侧、怎么读。

必须包含四样，顺序固定：

1. **定位**：「请看左侧表格」「请看图右上角红框」
2. **坐标/图例**：「横轴是 CDS 长度，纵轴是基因数」「红点是中央凹，灰点是外周」
3. **怎么看**：「每个点是一个细胞，越靠右表示某基因表达越高」
4. **观察到什么**：「从图中可以明显看出，两类细胞在 UMAP 上完全分开」

第 2、4 步是脚本硬查项：缺坐标/方位词（横轴、纵轴、行、列、颜色、区域、峰值）报错，
缺观察句（`可以看出 / 观察到 / 可以看到 / 可见 / 显示 / 说明`）也报错。

反例：❌「如图所示，结果符合预期。」——没有坐标、没有观察、没有信息。

## 4 So What 段怎么写

句式：`因此 + 结论`，紧接 `边界：…`。两句都要短。

脚本会查这一段的边界词：`so_what` 里必须出现「边界 / 局限 / 注意 / 适用条件 / 不代表 / 不等于 / 只能 / 仅在 / 不是 / 取决于 / 不能 / 前提是」之一，否则判错。

- ✅「因此类型身份在出生时已经建立。边界：这只是转录组层面，不能推出形态成熟。」
- ✅「因此三类检查共同支持解析正确。边界：数量一致只证明没漏读，坐标与方向仍未验证。」
- ❌「所以这个方法非常好，值得我们学习。」

**边界句的四种写法**（轮换使用，不要每页同一句）：
- 结论边界：`结论来自多 marker 的一致性，不能由单个基因一票决定。`
- 数据边界：`仅为转录组数据，未做蛋白水平验证。`
- 方法边界：`该结论依赖聚类分辨率，换参数可能改变类型数。`
- 适用边界：`只适用于当前注释层级，换成多转录本 GFF3 需重写。`

## 5 语言纪律

- 短句为主：一句话只讲一件事，用句号断开。
- 指代清晰：不说「这里」，说「图 3 右上角的红框」。
- 客观克制：用「数据显示 / 这表明 / 说明」，不用「我觉得 / 可能 / 或许」。
- 强调词留给关键处：`核心在于`、`值得注意的是`、`这直接说明`，每页最多两个。
- 口语化但不随意：可以「我们」，不要「咱们」「大家看这个玩意儿」。

## 6 页间衔接

每页 `speech.transition` 写一句翻页词，承接下一页：

| 上一页结尾 | 下一页开头 |
|---|---|
| 「字段清楚之后…」 | 「具体来说，我按 Parent 分组…」 |
| 「三类检查支持解析正确…」 | 「技术部分到此为止，下面转入单细胞。」 |
| 「因此蓝图保守、差异集中…」 | 「保守的是蓝图，那么特化发生在哪里？」 |

衔接句会以斜体单独排在讲稿每页末尾，不念也可，念了更顺。

## 7 输出格式

`build_script.py` 生成：

```
【第 3 页：Python 第 3 题：解析 GFF3 并统计 CDS】
〔Why｜动机引入〕   …
〔How｜具体做法〕   …
〔Read｜图表精读〕  …
〔So What｜结论与边界〕 …
→ 字段清楚之后，下一步是把这套规则翻译成代码。
```

同时在 `.pptx` 的**演讲者备注**里写入同样的四段（去标签），方便演示者视图直接看。

## 8 时长控制

- 每页 45–70 秒，按 230 字/分钟估算。
- 10 页 ≈ 10 分钟；15 页 ≈ 14 分钟。
- 超时优先砍 How 段的细节，**不要砍 Read 与 So What**（这是导师最关心的）。
- 讲稿开头不必写「各位老师好」，脚本会自动加结束语；开场直接进 Why。

## 9 自检清单

- [ ] 每页有四段（无图可省 Read）
- [ ] Read 段写了坐标轴 + 怎么看 + 看到什么
- [ ] So What 段有结论 + 边界
- [ ] 每页 ≤ 260 字，全文 ≤ 3500 字
- [ ] 没有「我觉得 / 可能 / 或许 / 大概」
- [ ] 每页末尾能自然引出下一页
