# 设计规格（Design Spec）

这套参数从本人第四/五/八周组会 PPT 中反解得到，**不要随意改动**。改一个数值，全年汇报就不一致了。

## 1 画布与网格

| 项 | 值 |
|---|---|
| 画布 | 33.87 × 19.05 cm（13.333 × 7.5 in，16:9） |
| 左边距 | 1.27 cm |
| 内容宽 | 30.9 cm（右边界 32.17） |
| 顶部色条 | (0, 0) 33.87 × 0.32，深蓝实心 |
| 标题区 | y 0.90 → 2.22（约占页面上方 1/5） |
| 导语带 | y 2.54，高 1.38 |
| 内容区 | y 4.45 → 16.0 |
| 总结句 | 贴内容区底部，y ≈ 16.1 → 17.3 |
| 页脚 | 章节名 y 17.96 左；页码右；y 18.71 处 30.9 × 0.11 深蓝横条 |

序号方块：`(1.27, 0.90) 1.38 × 1.11`，深蓝底、白字、13.5pt 加粗居中。
标题文字：`(3.07, 0.84) 29.1 × 1.40`，27pt 加粗，深蓝，左对齐，垂直居中。

## 2 配色（只用这些）

| 名称 | HEX | 用途 |
|---|---|---|
| 主色 深蓝 | `#084B82` | 标题、表头、序号块、页脚线、结论句 |
| 次级蓝 | `#176FA5` | 次级标题、文献来源标签 |
| 青绿 | `#27877B` | 正向强调、对照左栏、要点标题 |
| 橙 | `#D87838` | 注意 / 局限 / 反例（`warning` 类总结句） |
| 浅蓝 | `#49A6C7` | 序号小字（01/02/03）、点缀 |
| 正文墨 | `#1B2F41` | 正文、卡片标题 |
| 注释灰 | `#60788A` | 图注、页脚、次要说明 |
| 导语带底 | `#EDF5FA` | 导语圆角带 |
| 卡片底 | `#F6FAFD` | 卡片/对照栏 |
| 卡片描边 | `#C7DCE9` | 卡片 0.75pt 边线 |
| 标红 | `#C0392B` | 仅用于 `!!风险词!!` |
| 白 | `#FFFFFF` | 表头字、深色块上的字 |

规则：**一页最多出现 2 种强调色**（深蓝 + 青绿，或深蓝 + 橙）。橙色只给「注意/局限」，不要拿来做装饰。

## 4 版式线框

### cover
```
┌──────────┬───────────────────────────────┐
│ 深蓝竖块  │  主标题 27pt 深蓝（2–3 行）      │
│ 11.11cm  │  ────────── 0.13 横线          │
│          │  本周共读文献 16.5               │
│ 研究生    │  姓名 24                        │
│ 第X周组会 │  主题词 /  /  /  18 灰           │
│ 学习与…   │                       日期 13.5 │
│ 标签 15.75│                                │
└──────────┴───────────────────────────────┘
```

### part（模块过渡）
左侧同封面深蓝块 + 「第X周组会」44pt 白字；右侧 `Part 1` 60pt → 模块主题 54pt → 名称 40pt，
底部 0.13 横线 + 一行灰色说明（本模块几页、讲什么）。

### points（01/02/03 竖排）
```
[1] 标题 17.25 ────────────   ┌─────────────┐
    正文 14.25（≤3 句）        │  配图（可选） │
[2] 标题                     │             │
    正文                     └─────────────┘
[3] 标题                      图注 11.25 灰
    正文
```
序号用「泪滴」形 1.16 × 1.16，深蓝底白字。有配图时文字列宽 12.83，图区 x=17.2 宽 15。

### cards
2 张：各 14.95 宽；3 张：各 9.88 宽；4 张：2×2，各 14.95 × ≈5。
卡片 = 圆角矩形（`F6FAFD` 底 + `C7DCE9` 边）+ 左侧 0.19 宽强调竖条。
内部：optional 序号（浅蓝 12.75）→ 标题 18.75（强调色）→ 正文 15.75。
卡片高度按内容自适应（最小 5.2），整组垂直居中。

### table
表头深蓝底白字 14pt 加粗居中；正文 13pt，首列加粗深蓝；隔行 `F6FAFD` / 白。
行高按内容估算，多余高度均分（单行上限 2.3cm），整表在内容区垂直居中。
带 `side` 时表宽 16.4，右侧 2–3 张解读卡。

### flow
一行 3–5 个步骤卡，高 5.55，等宽（间距 0.58）。卡内：序号 12.75 浅蓝 → 标题 16.5 深蓝 → 正文 13.5。
下方可接 `panels`（2 栏对照，如「正链 / 负链」）。

### compare（慎用：对比一律用 table）
2–3 栏等宽卡片，高 ≈ 11.5。顶部可选 tag 胶囊（9pt 白字），标题 20pt 强调色，正文 15.75。
整块（tag + 标题 + 正文）在卡片内垂直居中。
**规范要求对比/并列信息一律用表格**，所以本版式只留给「三栏并列、但彼此不是对照关系」的场合
（如三个并列假说、三条独立路线）。A vs B 一律改用 `table`。

### figure
图占左侧 52%（或整宽），按原始比例缩放、居中，绝不拉伸；图注 11.25 灰置于图下；
右侧 2–3 组「序号 + 小标题 + 解读」（13.5）。

### stats
3–4 张大数字卡（数字 40pt 深蓝居中，标签 12pt 灰），可选下方 2 张说明块（13.5）。

### closing
同封面左侧深蓝块 + 右侧结束语 25pt 深蓝 + 署名 24 + 日期 13.5。

## 5 反例（不要做）

- ❌ 一页塞 4 个以上分块 → 拆页。
- ❌ 图片拉伸变形、图注省略编号。
- ❌ 用橙色做装饰色（橙色 = 注意/局限）。
- ❌ 标题写成「方法介绍」「实验结果」。
- ❌ 正文出现「我觉得」「可能」「或许」。
- ❌ 改了本文件的数值导致与往期不一致。
