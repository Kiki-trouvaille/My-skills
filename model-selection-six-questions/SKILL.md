# 模型选型六问（Scientific Model Selection Six Questions）

## Overview

面对一个科学建模任务，不要把"一句话 Prompt + 指定模型"直接交给 Agent 去写训练代码。这种做法会同时犯两类错误：**信息不足**，以及**还没理解数据就先指定了模型**，最终只能得到"能跑的代码 + 漂亮但不可审计的分数"。

本 Skill 把讲师提出的「模型选型六问」固化为一套可复用的提问流程：**先回答六问 → 得到建模需求说明书 → 再让 Agent 输出 数据审计 / baseline / 候选模型族与理由 / 划分与指标 / 风险与复现实验**。六问问完之后，模型选择范围会大幅缩小，剩下的工程调优（Grid Search、学习率、Batch Size 等）才是 Agent 最擅长的事情。

核心信条：**模型结构的本质是规定"谁和谁交换信息"；在 Agent 时代，把科学问题定义正确比默写算法更重要。**

## When to Use This Skill

在以下场景触发：

- 用户说"用 GNN / CNN / Transformer 拟合我的数据""帮我训练一个模型预测 XX"。
- 用户问"我这个数据该选什么模型""为什么用 GNN 不用 MLP"。
- 用户要"给 Agent 写一个建模 Prompt""把选型方法整理成 skill / 提问方式"。
- 需要为科学数据设计划分方案（train/val/test）、验证边界、baseline 与升级路径。
- 拿到一份新科研数据，在动手写代码前需要做数据审计与建模需求梳理。

## The Six Questions（决策卡）

训练开始前，逐项回答并写进 Prompt；任何一项答不上来，都应先向用户或领域专家确认，**不要替用户脑补**。

| # | 必答问题 | 写进 Prompt 的要点 | 决定选型的哪部分 | 常见错误 |
|---|----------|--------------------|------------------|----------|
| Q1 | 科学目标与任务类型？ | 目标变量、科学用途、回归/分类/排序/生成/聚类/异常检测 | 输出层、损失函数与指标；标签怎样构造；成功的科学含义 | 把"筛选（排序）"当"数值回归"做 |
| Q2 | "一个样本"是什么？ | 一个分子/构型/病人/样品/实验/时间窗口；哪些对象必须分组划分 | 有效独立样本数 N（而非文件行数）；划分是否真正独立 | 把同体系 1000 个构型当成独立样本 |
| Q3 | 数据模态与内在结构？ | 表格/图像/时序/图/序列/谱/场；邻接、顺序、坐标、多模态关系 | 候选架构族与 token/节点/像素定义；必须保留的关系 | 把有结构的数据拍平成表格，丢结构等于丢先验 |
| Q4 | 多少数据、多少标签？ | 有效 N、维度、噪声、缺失、重复、测量误差、类别不平衡、标注成本 | 模型容量、正则化、是否需要预训练；能负担多弱的先验 | N=200 时从头训练大型 Transformer |
| Q5 | 你知道哪些科学先验？ | 对称性、守恒量、单调性、局域性、周期边界、机理方程、不可行区域 | 是否需要等变网络、约束损失或机理耦合；数据效率与外推可信度 | 明知旋转/置换规律存在，却让普通 MLP 重新猜 |
| Q6 | 答案要长什么样？ | 可解释性、不确定性、推理成本、内插/外推、部署延迟、失败报警 | 黑箱是否可接受；是否需要 GP/集成/校准；验证集模拟哪种未来场景 | 需要机理解释时只交付一个黑箱分数 |

## Workflow

### Step 1 — 先拦截"直接写训练代码"的请求

当用户上来就指定模型并要求写代码时，不要直接执行。先说明：代码可以由 Agent 实现，但**选型论证必须先完成**；信息不足时先列出需要用户或领域专家确认的问题。

### Step 2 — 逐问交互，收集六问答案

按 Q1→Q6 顺序逐项询问或检查用户是否已经给出答案。对每一项：

- 若用户已给出，复述确认并写入建模需求说明书；
- 若信息不足，明确列出缺口并提问，不要自行假设；
- 对照上表"常见错误"一栏做风险提示（例如用户说"预测溶解度"时，追问是用于筛选排名还是定量精度）。

详细的逐问展开（写进 Prompt / 决定什么 / 常见错误 / 例子）见 `references/six_questions_detail.md`。

### Step 3 — 产出建模需求说明书

把六问答案整理成结构化说明书，至少包含：

1. 科学目标与任务类型（含评价指标）
2. 样本单位与划分单位（含必须分组的对象）
3. 数据模态与必须保留的结构
4. 有效 N / 标签 / 噪声 / 缺失
5. 已知科学先验（对称性、守恒、机理等）
6. 期望交付与外推边界（精度、不确定性、解释、成本）

### Step 4 — 让 Agent 按固定结构输出选型论证

要求 Agent 输出以下内容，而不是一上来就给训练代码：

```
数据审计 → baseline → 候选模型族与理由 → 划分/指标 → 风险与复现实验
```

- **数据审计**：按六问核对数据，指出潜在泄漏（同源记录、相邻片段、跨样本切 patch 等）。
- **baseline**：先给简单可靠的参照模型（表格数据先试线性/树模型）。
- **候选模型族**：给出 2–3 个候选并说明理由，把"数据结构 → 先验 → 架构"的对应关系讲清楚；不要只报一个名字。
- **划分/指标**：明确按什么单位切分（时间滚动、空间外推、按样品/家族分组），以及与 Q1/Q6 匹配的指标。
- **风险与复现实验**：说明假设、失败模式、以及需要跑哪些实验来确认最终模型。

### Step 5 — 交付后把调优工作交回 Agent

六问完成、候选确定后，并行实验（Grid Search、学习率、Batch Size、优化器）交给 Agent 自动执行；科学问题定义与数据处理仍由人负责。

## Prompt Template

把下面的骨架复制给用户，让其填充后交给 Agent（完整版见 `assets/six_questions_prompt.md`）：

```
请先不要直接写训练代码；若信息不足，先列出需要我或领域专家确认的问题。

Q1 目标：预测［具体性质］，属于［回归/分类/排序］；科学用途是［筛选/定量/解释］。
Q2 样本：确认一行对应分子还是构型；同一实体必须分组划分。
Q3 模态：比较描述符、SMILES、2D 图、3D 坐标各自保留/丢失的信息。
Q4 规模：报告有效独立 N、标签数、缺失、噪声与重复；不要把同源记录当独立样本。
Q5 先验：确认置换、旋转/平移不变或等变、局域性与其他机理约束。
Q6 交付：除精度外报告不确定性、外推、可解释性与推理成本。

请输出：数据审计 → baseline → 候选模型族与理由 → 划分/指标 → 风险与复现实验。
```

## Anti-Patterns（必须避免）

- **不要让 Agent 直接写训练代码**：先完成六问，得到建模需求说明书。
- **不要替用户脑补缺失信息**：信息不足先提问，尤其 Q2（样本单位）与 Q5（先验）。
- **不要只给一个模型名字**：给出 2–3 个候选族 + 理由，并说明验证如何区分它们。
- **不要随机切分科学数据**：按样品/家族/时间/空间外推切分，检查同源泄漏。
- **不要把有结构的数据拍平成表格**：表示选择就是先验选择。
- **不要在没有可信方程时硬塞 PINN**：错误物理先验会变成错误约束；数据充足时可让模型自己学。
- **不要用 R²/ACC 单一指标交付**：按 Q6 交付不确定性、外推边界与可解释性。

## Quick Reference：数据结构 → 候选先验

| 自然输入 | 信息路径 / 先验 | 典型用途 |
|----------|-----------------|----------|
| 固定长度向量 | 全连接；弱结构先验 | 表格 baseline（MLP、树模型） |
| 规则网格 / 图像 | 局部连接 + 权重共享 | 视觉、网格场（CNN） |
| 有序序列 | 状态递推；门控记忆 | 语音、文本、时序（RNN/LSTM） |
| token / patch | 内容相关全局连接 | 理解、生成、跨模态（Transformer/ViT） |
| 节点—边图 | 沿边消息传递 | 分子、晶体、网络（GNN） |
| 坐标 / 场 | PDE / 守恒残差进 loss | 物理场与逆问题（PINN） |

注意：不要把这张表当成"数据类型 ↔ 模型名字"的一一对应表。它只是候选起点，最终选择必须由六问的答案（尤其 Q3/Q5/Q4）论证。
