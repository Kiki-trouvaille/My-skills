# 模型选型六问 · 逐问详解

本文件是 SKILL.md 的展开参考，用于逐问交互时查证。内容源自李文毅《科学模型专题（二）》PPT 第 33–39 页。

---

## Q1｜科学目标与任务类型？

**先把"拟合"翻译成可验证任务。**

- 写进 Prompt：目标变量、科学用途、回归 / 分类 / 排序 / 生成 / 聚类 / 异常检测。
- 决定：输出层、损失函数与指标；决定标签怎样构造，以及成功的科学含义。
- 常见错误：把"筛选优先级"当成"数值回归"做。
- 课堂例子：药物候选筛选关心前 1% 排名；即使 RMSE 尚可，排序也可能很差。此时应关注排序指标（如 NDCG、 Recall@1%），而不是 RMSE。
- 金句：任务不是数据集自带的标签名，而是你准备怎样使用答案。

追问模板：
- "你最终要拿这个预测结果做什么？定量报告、筛选排名，还是机理解释？"
- "如果模型数值误差小但排序差，这个任务算成功吗？"

---

## Q2｜"一个样本"是什么？

**有效样本量 N 与划分单位必须一起写。**

- 写进 Prompt：一个分子 / 构型 / 病人 / 样品 / 实验 / 时间窗口；哪些对象必须分组划分。
- 决定：有效独立样本数，而非文件行数；决定训练/验证/测试是否真正独立。
- 常见错误：把同一体系 1000 个构型当成 1000 个独立样本；同一病人的多张切片若跨训练与测试，模型可能只认出了病人。
- 课堂例子：同一分子跑很多遍产生 1000 条记录，实际独立样本可能只有 1 个；有效文件数 ≠ 有效样本数。
- 金句：不先定义科学独立性，再统计 N；否则漂亮指标可能只是同源泄漏。

追问模板：
- "一行数据对应一个独立的研究对象，还是同一对象的重复测量？"
- "有没有必须整组划分的实体（同一分子/病人/样品/时间窗口）？"

---

## Q3｜数据模态与内在结构？

**写清数据元素、关系与表示。**

- 写进 Prompt：表格 / 图像 / 时序 / 图 / 序列 / 谱 / 场；邻接、顺序、坐标、多模态关系。
- 决定：候选架构族与 token / 节点 / 像素定义；决定哪些关系必须保留、哪些变换不应改变语义。
- 常见错误：把有结构的数据拍平成表格，丢结构等于丢先验。
- 课堂例子：分子可表示为描述符、SMILES、2D 图或 3D 坐标；候选模型随表示改变。同一个蛋白质可以是氨基酸序列、3D 结构或残基图，表示不同，模型看到的信息不同。
- 金句：数据模态不是文件格式；真正重要的是内部关系怎样进入计算。

追问模板：
- "一个样本内部有哪些元素？它们之间有什么关系（邻接、顺序、坐标、拓扑）？"
- "同一对象还有哪些表示？换表示会保留/丢失什么信息？"

---

## Q4｜多少数据、多少标签？

**报告有效 N、维度、噪声与标注成本。**

- 写进 Prompt：独立样本数、标签比例、缺失、重复、测量误差、类别不平衡、预训练资源。
- 决定：模型容量、正则化与是否需要预训练；决定能负担多弱的归纳偏置与多复杂的验证。
- 常见错误：N = 200 时从头训练一个大型 Transformer。
- 课堂例子：小数据表格先比较线性/树模型；结构明确时再尝试更强先验网络。
- 金句：样本少时，正确先验与可靠验证通常比增加参数更值钱。

追问模板：
- "去掉重复与同源记录后，真正独立的样本有多少？"
- "标签是怎么得到的？有没有噪声、缺失、类别不平衡？"

---

## Q5｜你知道哪些科学先验？

**把不会改变的规律写进模型或约束。**

- 写进 Prompt：对称性、守恒量、单调性、局域性、周期边界、机理方程、已知不可行区域。
- 决定：缩小假设空间，提高数据效率与外推可信度；决定是否需要等变网络、约束损失或机理耦合。
- 常见错误：明知旋转/置换规律存在，却让普通 MLP 重新从数据里猜。
- 课堂例子：刚性旋转一个 3D 结构，标量能量应保持（不变），力的方向则应随坐标一起旋转（等变）。
- 金句：科学家相对纯 AI 工程师的优势，不只是数据，而是知道哪些规律绝不该被违反。
- 警告：没有可信、可微的物理方程时不要硬上 PINN——错误物理先验会变成错误约束；数据充足时可让模型自己学。

追问模板：
- "坐标系旋转/平移/置换后，答案应该不变还是随之变化？"
- "有没有守恒量、单调性、周期边界或已知不可行区域可以写进模型？"

---

## Q6｜答案要长什么样？

**精度之外，还要定义怎样被相信和使用。**

- 写进 Prompt：可解释性、不确定性、推理成本、内插 / 外推、部署延迟、失败时如何报警。
- 决定：是否能接受黑箱，以及是否需要 GP、集成或校准；决定验证集应模拟哪一种未来使用场景。
- 常见错误：需要机理解释时，只交付一个黑箱分数。
- 课堂例子：实验排队资源有限时，模型应同时给预测与不确定性，帮助决定下一次测什么。
- 金句：模型选型的终点不是排行榜第一，而是得到一个在目标场景中可用、可信的答案。

追问模板：
- "除了 ACC/R²，还需要报告不确定性、可解释性或外推能力吗？"
- "验证集要模拟哪种未来场景——新时间、新地点，还是新体系？"
