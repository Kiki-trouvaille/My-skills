# 六问版 Prompt 模板（可直接复制给 Agent）

## 用法

把下面的骨架复制给用户，让其填充方括号内容后交给 Agent。骨架中的每条都是硬性要求：任何一项信息缺失，Agent 应先提问，而不是自行脑补后直接写训练代码。

---

## 骨架（原文）

```
请先不要直接写训练代码；若信息不足，先列出需要我或领域专家确认的问题。

Q1 目标
预测［具体性质］，属于［回归/分类/排序］；科学用途是［筛选/定量/解释］。

Q2 样本
确认一行对应分子还是构型；同一实体必须分组划分。

Q3 模态
比较描述符、SMILES、2D 图、3D 坐标各自保留/丢失的信息。

Q4 规模
报告有效独立 N、标签数、缺失、噪声与重复；不要把同源记录当独立样本。

Q5 先验
确认置换、旋转/平移不变或等变、局域性与其他机理约束。

Q6 交付
除精度外报告不确定性、外推、可解释性与推理成本。

请输出：数据审计 → baseline → 候选模型族与理由 → 划分/指标 → 风险与复现实验。
```

---

## 填空示例（药物候选筛选）

```
请先不要直接写训练代码；若信息不足，先列出需要我或领域专家确认的问题。

Q1 目标
预测候选分子的抑制活性 IC50，属于排序；科学用途是从 10 万个候选里挑出最值得做实验的前 1%。
（注意：评价指标用 Recall@1% / NDCG，而不是 RMSE。）

Q2 样本
一行对应一个分子；同一分子的多次重复测量必须分组划分，不能跨训练/测试。

Q3 模态
请比较 descriptors、SMILES、2D 图、3D 坐标四种表示各自保留/丢失的信息，并给出候选模型族。

Q4 规模
data 下有 10 万行，但独立分子约 8000 个；标签来自文献 IC50，约 30% 缺失，存在批次效应。

Q5 先验
分子能量应对刚性旋转/平移保持不变；分子图具有置换不变性；请确认是否使用等变网络。

Q6 交付
除排序指标外，报告预测不确定性（用于决定下一次测什么），并给出可解释的构效关系分析。

请输出：数据审计 → baseline（线性/树模型 + 简单指纹）→ 候选模型族与理由（GNN / 3D 等变网络 / Transformer）→ 划分/指标（按分子骨架分组，Recall@1%）→ 风险与复现实验（同源泄漏检查、消融实验）。
```

## 与原 Prompt 的对比

| | 原 Prompt | 六问版 Prompt |
|---|-----------|---------------|
| 内容 | "请用 GNN 拟合 data 下的分子数据" | 先声明不要直接写代码，再逐项回答 Q1–Q6 |
| 目标 | 未说明 | 明确任务类型与科学用途 |
| 样本 | 未定义 | 明确样本单位与分组划分 |
| 表示 | 未指定 | 比较多种表示的取舍 |
| 规模 | 未统计 | 报告有效独立 N 与噪声 |
| 先验 | 未写入 | 明确对称性与机理约束 |
| 交付 | 只要分数 | 精度 + 不确定性 + 解释 + 外推 |
| 输出 | 能跑的代码 + 漂亮但不可审计的分数 | 数据审计 → baseline → 候选族 → 划分/指标 → 风险与复现实验 |
